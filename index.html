How this works

  • A GitHub Actions cron polls the Wellfitness portal for live headcounts in all ~105 clubs.
  • Every sample is committed to this repo as CSV; this page reads those files directly and recomputes on each load.
  • No server anywhere — the charts get richer automatically as data accumulates.

Reading the numbers

  • The portal reports no capacity, so clubs aren't compared on raw headcounts — each club is measured against its own typical peak.
  • Cells show the median, so a single holiday or bad sample doesn't skew the picture.
  • All times are Europe/Warsaw (DST-safe), converted from UTC storage.
